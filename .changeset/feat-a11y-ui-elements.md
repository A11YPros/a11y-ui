feat: initial release of @a11ypros/a11y-ui-elements (Accessible Web Components)

- Includes 12 framework-agnostic accessible Custom Elements:
  - `<a11y-button>`
  - `<a11y-switch>`
  - `<a11y-modal>`
  - `<a11y-accordion>`
  - `<a11y-tabs>`
  - `<a11y-data-table>`
  - `<a11y-tooltip>`
  - `<a11y-banner>`
  - `<a11y-link>`
  - `<a11y-menu>`
  - `<a11y-menubar>`
  - Form suite: `<a11y-input>`, `<a11y-textarea>`, `<a11y-select>`, `<a11y-checkbox>`, `<a11y-radio>`, `<a11y-fieldset>`, and `<a11y-label>`
- Built for WCAG 2.1 / 2.2 AA & AAA compliance with full keyboard navigation and ARIA live regions.
- Provides ESM modular exports and standalone IIFE browser bundle with TypeScript types.
